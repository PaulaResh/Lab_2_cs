# ЗАДАНИЕ 1. ТОЧКА

## ТЕКСТ ЗАДАЧИ:

Создайте сущность Точка, расположенную на двумерной плоскости, которая описывается:
- Координата Х: число
- Координата Y: число
- Может возвращать текстовое представление вида {X;Y}

Необходимо создать три точки с разными координатами и вывести на экран их текстовое представление.

## АЛГОРИТМ РЕШЕНИЯ:

1. Создать класс Point, наследующий абстрактный класс Shape.
2. Реализовать приватные поля _x и _y с соответствующими
   свойствами X и Y типа double.
3. Реализовать конструктор, принимающий обе координаты, и
   передающий базовому классу имя "Точка".
4. Переопределить метод GetInfo(), возвращающий строку вида
   {X;Y} с использованием интерполяции строк.
5. В методе Main создать три объекта Point с различными
   координатами, введёнными с клавиатуры, и вывести их.

# ЗАДАНИЕ 2. ЛИНИЯ

## ТЕКСТ ЗАДАЧИ:

Создайте сущность Линия, расположенную на двумерной плоскости, которая описывается:
- Координата начала: Точка
- Координата конца: Точка
- Может возвращать текстовое представление вида "Линия от {X1;Y1} до {X2;Y2}"

Для указания координат нужно использовать сущность Точка. Необходимо:
1. Создать линию 1 с началом в т. {1;3} и концом в т. {23;8}.
2. Создать линию 2, горизонтальную, на высоте 10, от точки 5 до точки 25.
3. Создать линию 3, которая начинается там же, где начинается линия 1, и заканчивается там же, где заканчивается линия 2.
4. Изменить координаты первой и второй линий так, чтобы третья линия также изменилась.
5. Изменить координаты первой линии так, чтобы третья линия не изменилась.

## АЛГОРИТМ РЕШЕНИЯ:

1. Создать класс Line, наследующий Shape, со свойствами Start
   и End типа Point.
2. Реализовать конструктор, принимающий две точки, и передать
   базовому классу имя "Линия".
3. Переопределить GetInfo() для вывода в требуемом формате.
4. При создании линии 3 передать ссылки на точки из линий 1 и
   2 - благодаря этому изменение координат точек отразится на
   всех линиях.
5. Для пункта 4 изменять значения X и Y у существующих объектов
   Point (мутация объекта).
6. Для пункта 5 заменить ссылку Start у линии 1 на новый объект
   Point - тогда линия 3 продолжит ссылаться на старый объект.

# ЗАДАНИЕ 3. СТУДЕНТ

## ТЕКСТ ЗАДАЧИ:

Создайте сущность Студент, которая описывается:
- Имя: строка
- Оценки: массив целых чисел
- Может возвращать текстовое представление вида "Имя: [оценка1, оценка2,…,оценкаN]"

Необходимо:
1. Создать студента Васю с оценками 3, 4, 5.
2. Создать студента Петю и скопировать ему оценки Васи (присвоить поле с оценками).
3. Заменить первую оценку Пети на 5. Вывести Васю и Петю. Объяснить результат.
4. Создать студента Андрея и скопировать ему оценки Васи так, чтобы изменение оценок Васи не влияло на Андрея.

## АЛГОРИТМ РЕШЕНИЯ:

1. Создать класс Student, наследующий класс Person.
2. Добавить приватное поле _grades типа int[] и свойство Grades.
3. В конструкторе вызвать base(name) для инициализации имени.
4. Переопределить ToString(), используя string.Join для массива.
5. При создании Пети присвоить vasya.Grades напрямую - это
   поверхностное копирование, копируется ссылка на массив.
6. При создании Андрея использовать метод Clone() для глубокого
   копирования массива - создаётся независимый массив.

# ЗАДАНИЕ 4. МОДИФИЦИРОВАННЫЕ ТОЧКА И ЛИНИЯ

## ТЕКСТ ЗАДАЧИ:

4.1. Точка. Измените сущность Точка так, чтобы создать объект можно было только путём указания обеих координат X и Y. Создать и вывести точки с координатами {3;5}, {25;6}, {7;8}.

4.2. Линия. Измените сущность Линия. Новые требования:
- Создание возможно с указанием двух объектов Point.
- Создание возможно с указанием четырёх чисел (x1, y1, x2, y2).

Создать три линии:
1. С началом в {1;3} и концом в {23;8}.
2. Горизонтальную на высоте 10 от точки 5 до точки 25.
3. Начинающуюся там же, где линия 1, и заканчивающуюся там же, где линия 2.

## АЛГОРИТМ РЕШЕНИЯ:

1. В классе Point оставить только один конструктор с двумя параметрами — это гарантирует, что объект нельзя создать без указания обеих координат.
2. В классе Line реализовать перегрузку конструкторов: один принимает два объекта Point, второй — четыре числа типа double и создаёт точки внутри себя.

# ЗАДАНИЕ 5. ДЛИНА ЛИНИИ

## ТЕКСТ ЗАДАЧИ:

Измените сущность Линия. Добавьте ей возможность возвращать по запросу пользователя расстояние между точками начала и конца в виде целого числа. Создайте линию из точки {1;1} в точку {10;15} и выведите её длину.

## АЛГОРИТМ РЕШЕНИЯ:

1. Добавить метод GetLength(), вычисляющий расстояние по
   теореме Пифагора: √((x2-x1)² + (y2-y1)²).
2. Использовать Math.Sqrt() для извлечения корня.
3. Результат округлить методом Math.Round() и привести к типу
   int через явное преобразование (int).
